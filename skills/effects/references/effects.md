# Параметры эффектов

Все параметры задаются через `--set ключ=значение` или файлом `--params`. Списки и объекты пиши в JSON: `--set 'items=["Сняли","Смонтировали","Выложили"]'`. Один элемент списка: `--set items.0=Сняли`, `--set covers.2.label=МОЙ КАНАЛ`.

Общее для всех эффектов: `--face X,Y,W,H` (рамка головы), `--at` (секунда начала), `--dur` (длительность), `--words` (файл расшифровки), `--set frames.N=путь` (заменить кадр записи своей картинкой из папки проекта).

## glass-widgets

Стеклянные карточки парят вокруг головы: число с подписью, диаграмма, прогресс, карточка автора, кольцо, пилюля. На поясном плане карточки стоят по бокам от головы, на крупном — рядом под подбородком (три карточки и пилюля). Длительность по умолчанию 3,0 с.

| Параметр | Что это | По умолчанию |
| --- | --- | --- |
| `brand` | название рядом со звёздочкой | `"Claude"` |
| `big` | крупное число или короткое слово | `"7"` |
| `bigLabel` | подпись под числом | `"эффектов · одна запись"` |
| `statTitle` | заголовок карточки с диаграммой | `"Рендер в 4K"` |
| `progressLabel` | подпись полосы прогресса | `"Рендеринг"` |
| `name` | имя автора | `"Твоё имя"` |
| `handle` | ник автора | `"@твой_ник"` |
| `ring` | надпись в кольце | `"4K"` |
| `pill` | текст пилюли под лицом | `"Edited by Claude"` |
| `pillAccent` | часть текста пилюли, которая красится в цвет акцента | `"Claude"` |
| `accent` | цвет акцента | `"#D97757"` |

Аватар в карточке автора берётся из второго кадра записи (`frames.1`).

## orbit

Шесть вертикальных обложек летят по орбите: задние меньше и тусклее. На поясном плане орбита идёт над головой, на крупном — под подбородком. Длительность по умолчанию 3,2 с.

| Параметр | Что это | По умолчанию |
| --- | --- | --- |
| `covers` | шесть объектов `{label, color}`: подпись на плашке и цвет плашки | `[{"label": "TODO", "color": "#22C55E"}, {"label": "SWITCHES", "colo…` |

Картинки обложек — шесть кадров записи (`frames.0` … `frames.5`). Свои обложки: положи файлы в `assets/img/` проекта и подставь `--set frames.0=assets/img/cover1.jpg`.

## spotlight

Кадр темнеет к краям, человек остаётся в светлом пятне, рядом загорается неоновая надпись. Длительность по умолчанию 2,6 с.

| Параметр | Что это | По умолчанию |
| --- | --- | --- |
| `neon` | неоновая надпись, лучше одно короткое слово | `"CLAUDE"` |
| `color` | цвет неона | `"#FF5FA8"` |
| `dim` | плотность затемнения по краям, от 0 до 1 | `0.92` |

## todo

Тёмная карточка со списком под подбородком: кружки по очереди становятся галочками, счётчик растёт. Со словами речи галочки ставятся на словах. Длительность по умолчанию 4,3 с.

| Параметр | Что это | По умолчанию |
| --- | --- | --- |
| `title` | заголовок карточки | `"Claude монтирует твой ролик"` |
| `items` | строки списка, от 3 до 6 | `["Нашёл лицо", "Вырезал тебя из комнаты", "Поставил текст за спину"…` |
| `tags` | короткие подписи справа у строк, столько же, сколько строк; можно пустые | `["каждый кадр", "289 масок", "глубина", "тепло", "2160p"]` |
| `of` | слово в счётчике «2 из 5» | `"из"` |

Длинная строка обрезается многоточием: держи пункт в пределах 20–25 знаков. Подписи `tags` идут парой к `items`: задал свои пункты и не задал подписи — подписи не показываются.

## timeline

Внизу кадра панель-монтажка с дорожками, светящийся бегунок едет слева направо, процент рендера растёт до 100. Длительность по умолчанию 3,6 с.

| Параметр | Что это | По умолчанию |
| --- | --- | --- |
| `brand` | первое слово заголовка над панелью | `"Claude"` |
| `titleAccent` | второе слово заголовка, курсивом | `"рендерит"` |
| `header` | подпись слева в шапке панели | `"CLAUDE · РЕНДЕР"` |
| `headerRight` | подпись справа в шапке панели | `"4K · 30 FPS"` |
| `tracks` | четыре подписи дорожек | `["КЛИП", "ТИТРЫ", "ЦВЕТ", "ЗВУК"]` |
| `chips` | три блока на дорожке титров | `["одна запись", "/effects", "7 правок"]` |
| `from` | с какого процента стартует счётчик | `65` |

Плёнка на дорожке клипа — кадры записи.

## match-cut

Быстрая смена пяти «газетных» полос на весь кадр, слово стоит в одной точке. В конце полосы исчезают, слово остаётся на видео под лицом. Единственный эффект, который закрывает лицо намеренно. Длительность по умолчанию 3,2 с.

| Параметр | Что это | По умолчанию |
| --- | --- | --- |
| `word` | слово, которое стоит на месте | `"Claude"` |
| `headlines` | пять объектов `{before, after}`: текст заголовка до слова и после него | `[{"before": "Я отдал", "after": "монтаж своих роликов"}, {"before":…` |
| `papers` | пять названий: имя папки в терминале и четыре издания | `["my_reels/", "ФОНАРЬ", "СИГНАЛ", "Утренняя схема", "Tech-вестник"]` |
| `terminal` | строки терминала на первой полосе, последняя — с галочкой | `["$ claude", "› /effects orbit", "› /effects todo", "готово"]` |
| `rubric` | рубрика на третьей полосе | `"ИНСТРУМЕНТЫ АВТОРА"` |
| `tag` | тег на пятой полосе | `"AI-ВИДЕО"` |
| `captions` | две мелкие подписи внизу полос | `["Технологии · Авторский разбор", "Одна запись, семь эффектов и ни …` |

Если слово встречается в речи в окне эффекта, полосы исчезают на нём.

## toggles

Под лицом выезжает светлая панель с тремя переключателями, они включаются по очереди. Со словами речи — на словах. Длительность по умолчанию 2,8 с.

| Параметр | Что это | По умолчанию |
| --- | --- | --- |
| `items` | подписи переключателей, до трёх | `["Хороший свет", "Главный герой", "Edited by Claude"]` |
| `on` | цвет включённого переключателя | `"#34C759"` |
