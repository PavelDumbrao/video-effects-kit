# Контракт шаблона эффекта

Этот файл читает тот, кто пишет или правит шаблон эффекта: ты или твой агент. Шаблон — сцена HyperFrames, которая ложится поверх вертикального видео с говорящим человеком.

## Где что лежит

```
effects/                   папка навыка
  SKILL.md                 порядок работы агента
  references/contract.md   этот файл
  references/effects.md    параметры эффектов
  scripts/fx.py            готовит проект и ставит эффекты
  templates/effects.json   реестр: длительность и параметры каждого эффекта
  templates/<эффект>.html  шаблон сцены
```

Проект, который создаёт `fx.py prepare`:

```
<проект>/
  index.html                 корневая композиция 1080×1920, 30 к/с: видео и эффекты
  hyperframes.json
  fx.json                    состояние: длительность видео и список эффектов
  assets/video/source.mp4    запись, приведённая к 1080×1920
  assets/frames/f1.jpg…f6.jpg  шесть кадров записи 540×960 (обложки и фото для эффектов)
  frames/face.jpg            кадр 1080×1920, по нему агент определяет рамку головы
  compositions/<id>.html     эффект с подставленными параметрами
```

## Каркас шаблона (строго)

```html
<template>
<style>
#root{position:absolute;inset:0;overflow:hidden;font-family:'Inter',sans-serif}
#root *{box-sizing:border-box}
/* все id и классы начинаются с __ID__- */
</style>
<div id="root" data-composition-id="__ID__" data-start="0" data-duration="@@DUR@@" data-width="1080" data-height="1920">
 <div id="__ID__-clip" class="clip" data-start="0" data-duration="@@DUR@@" style="position:absolute;left:0;top:0;width:1080px;height:1920px;overflow:hidden">
   <!-- элементы эффекта -->
 </div>
</div>
<script>
(function(){
 const P=/*@@P@@*/{};
 const tl=gsap.timeline({paused:true});
 // раскладка по P.face, затем анимация
 window.__timelines=window.__timelines||{}; window.__timelines['__ID__']=tl;
})();
</script>
</template>
```

`fx.py add` подставляет:

| Токен | Что подставляется |
| --- | --- |
| `__ID__` | id экземпляра, например `fxtodo1` (только латиница и цифры) |
| `@@DUR@@` | длительность эффекта в секундах |
| `/*@@P@@*/{}` | объект параметров `P` |
| `@@F1@@` … `@@F6@@` | пути к кадрам записи (`P.frames[0..5]`); писать только внутри `src="…"` |

Самый маленький рабочий пример — `templates/_probe.html`: рамка вокруг головы, плашка и кадр записи. С него удобно начинать свой эффект: `fx.py add _probe …`.

## Объект P

```js
{
  id: "fxtodo1",
  dur: 4.3,                       // секунды, как в @@DUR@@
  W: 1080, H: 1920,
  face: {x: 370, y: 390, w: 330, h: 500, cx: 535, cy: 640},  // рамка головы: от макушки до подбородка, от уха до уха
  words: [{w: "слово", s: 0.42, e: 0.71}],                   // слова речи в окне эффекта, время от начала эффекта; может быть пустым
  frames: ["assets/frames/f1.jpg", …],                       // шесть кадров записи
  …параметры эффекта из templates/effects.json, поверх них то, что задал человек
}
```

Все тексты, цвета и списки эффекта — параметры с русскими значениями по умолчанию в `templates/effects.json`. В шаблоне текст ставится из `P` (`el.textContent = P.title`), в разметке остаётся запасное значение.

## Правила кода сцены

1. Время идёт только через `tl`: `tl.set`, `tl.to`, `tl.fromTo`. У второго и следующих `fromTo` на том же элементе ставь `immediateRender:false`.
2. Запрещены `Math.random()`, `Date`, `requestAnimationFrame`, `setTimeout`, `setInterval`: рендер должен давать один и тот же кадр на одной и той же секунде.
3. Печать текста: твин вспомогательного объекта с `onUpdate`, который пишет `textContent`.
4. Ничего не начинается позже `P.dur - 0.15`. Эффект появляется за первые 0,2–0,3 с и уходит за последние 0,2–0,3 с: в начале и в конце окна кадр чистый.
5. События привязывай к словам, если они есть (`P.words[i].s`), иначе к долям `P.dur`. Слов может не быть совсем.
6. Шрифты только встроенные в HyperFrames: `Inter`, `Playfair Display`, `JetBrains Mono`.
7. Значки только inline SVG, не символы шрифта и не эмодзи.
8. Текст не мельче 28 px. Длинная строка из параметров не ломает раскладку: уменьшай кегль по длине строки или обрезай с многоточием.
9. Тяжёлых элементов (`filter:blur`, `radial-gradient`, `clip-path`, большие тени) не больше 20 на сцену. `backdrop-filter` не используй: стекло делай полупрозрачным белым `rgba(255,255,255,.72)` с белой рамкой и тенью.
10. Пути к картинкам — только токены `@@F1@@…@@F6@@` в атрибуте `src`. Не собирай путь из строк в коде.
11. Не анимируй сам элемент `.clip`: анимируй его детей.

## Раскладка под любое лицо

Положение головы заранее неизвестно. Шаблон читает `P.face` и расставляет элементы до построения таймлайна (`el.style.left`, `el.style.top`, размеры).

- Лицо не закрывать. Запретная зона — рамка головы, расширенная на 6 % в каждую сторону. Исключение — эффекты, которые закрывают кадр намеренно (`match-cut`).
- Зоны кадра. Сверху, снизу и справа внизу кадр перекрывает интерфейс соцсети (шапка, подпись, кнопки).
  - Лучшее место для важного: x 120–890, y 290–1250 (безопасная зона HyperFrames для вертикали; ниже y 840 справа держись до x 900).
  - Допустимо, когда лицо не оставляет места: x 40–1040, y 170–1500. `check` при этом предупредит `outside_safe_zone` — это предупреждение, не ошибка.
  - Предел: ниже y 1620 и выше y 150 ничего важного.
- Проверяй три случая:
  - крупный план: `face = {x:220, y:120, w:720, h:1120}` — по бокам места нет, элементы уходят над голову и под подбородок;
  - поясной план: `face = {x:370, y:390, w:330, h:500}` — места много, элементы стоят по бокам от головы;
  - голова в левой трети: `face = {x:120, y:420, w:340, h:520}` — элементы перестраиваются на свободную сторону.
- Если для элемента места нет, уменьши его или убери: лучше меньше элементов, чем закрытое лицо.

## Приёмка шаблона

1. `npx hyperframes check --json` в проекте: ошибок нет.
2. Кадры `npx hyperframes snapshot --at <t1,t2,t3,t4>` для крупного и поясного плана: лицо открыто, текст читается с телефона, ничего не обрезано краем кадра.
3. Кадр на первой и на последней 0,05 с окна эффекта чистый: эффекта ещё нет или уже нет.
